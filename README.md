# ☄️ Hazardous Asteroid Classification

A machine learning project that predicts whether an asteroid is **potentially hazardous** based on its physical and orbital characteristics.  
The final model is deployed using **Streamlit** for interactive predictions.

---
## 📊 Dataset & Sources
This project uses **official and public asteroid data** from:

- **NASA** 🔗 https://data.nasa.gov/dataset/meteorite-landings
- **The Minor Planet Center** 🔗 https://www.minorplanetcenter.net/data

---

## 🚀 Features
- Binary classification: Hazardous vs Non-Hazardous
- Multiple ML models tested (Logistic Regression, Random Forest, SVM, KNN, Decision Tree)
- Evaluation using Accuracy, Precision, Recall, F1-Score, and ROC-AUC
- Deployed as a web app with Streamlit

---

## 🧠 Tech Stack
- Python
- Scikit-learn
- Pandas / NumPy
- Streamlit
- Joblib
